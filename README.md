# Intelligent Energy Systems Course

**Control Systems → Optimization → Reinforcement Learning → Multi-Agent Systems → Game Theory**

Complete hands-on course with three full professional projects.

## Course Goal

By the end of this course you will be able to:

- Design and implement classical and modern controllers (ON/OFF, P, PI, PID)
- Model physical systems and simulate them
- Formulate energy management problems as Markov Decision Processes
- Implement tabular Q-Learning, Deep Q-Networks (DQN) and PPO from (or close to) scratch
- Understand and implement core game-theoretic concepts (Nash, auctions, Stackelberg)
- Build multi-agent energy market simulations
- Connect control theory, RL and game theory into intelligent energy systems

## Recommended Learning Order

1. **Project 1 – Control Systems** (fundamentals of feedback, modeling, PID)
2. **Project 2 – Reinforcement Learning** (sequential decision making under uncertainty)
3. **Project 3 – Game Theory** (strategic interaction between multiple agents)
4. Connect all three: multi-agent RL in energy markets

## Prerequisites

- Python (intermediate)
- Basic linear algebra and calculus (we explain the math we use)
- Curiosity about energy systems (solar, batteries, microgrids)

## How to use this course

1. Clone all three project repositories + this course guide.
2. Work through Project 1 completely (run the code, change gains, add disturbances).
3. Move to Project 2 and implement / experiment with the agents.
4. Finish with Project 3.
5. Read the connection and interview documents.
